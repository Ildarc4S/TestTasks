Скрипт для извлечения уникальных номеров банковских карт из текстовых файлов.

## Использование

```bash
./find_pan.sh [файл]
./find_pan.sh --help
```

- `файл` - входной файл (по умолчанию: trans.txt)
- `--help` - показать справку

## Примеры

```bash
./find_pan.sh                     # Использует trans.txt
./find_pan.sh my_transactions.txt # Использует указанный файл
```

## Формат данных

Ищет номера карт в формате: `PAN: 1234567890123456`. Где номер содержит 13-19 цифр.

## Вывод

Скрипт выводит уникальные номера карт, по одному на строку:
```text
1234567890123456
9876543210987654
```

## Устройство

Под капотом используется `grep` с поиском по шаблону `"PAN: [0-9]{13,19}"` и утилита сортировки `sort`.
